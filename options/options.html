NowJump

A command palette for ServiceNow. Press Ctrl K on any instance page.

Try it: open any instance, press the shortcut, type ecc, press Enter. Paste a sys_id to jump straight to its record. Type > to see only actions for the record you have open.

Instance domains

NowJump runs on *.service-now.com by default. If your instance uses its own domain, add it here. Chrome will ask you to allow the extension on that site; nothing is enabled until you accept.

    Stored data

    NowJump keeps recents per instance in this browser only: table names, sys_ids, labels and timestamps. Never record content, never synced, never sent anywhere.
