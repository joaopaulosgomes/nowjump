# NowJump - Privacy Policy

**Last updated:** 22/09/2026

## What NowJump does

NowJump is a Chrome extension that provides a keyboard-activated command palette for navigating ServiceNow instances. It reads the current page's URL and DOM elements to determine context (instance name, table, sys_id) and lets users jump to records, tables, and related items without leaving the current page.

## Data collected

NowJump reads limited **website content** from ServiceNow instance pages only:

- The current page URL to identify the ServiceNow instance, table, and record
- DOM elements to extract contextual information (sys_id, form fields, related lists)

This data is used exclusively to power the command palette's navigation features within the active browser tab.

## Data stored locally

NowJump stores the following in `chrome.storage.local` on your device:

- User preferences (keyboard shortcut, theme settings)
- Recently used navigation targets for faster repeat access

This data never leaves your browser.

## Data NOT collected

NowJump does **not**:

- Collect personally identifiable information
- Track browsing history or user activity
- Send any data to external servers or third parties
- Use analytics, telemetry, or crash reporting
- Access pages outside of ServiceNow instances

## Data sharing

NowJump does not sell, transfer, or share any user data with third parties.
